

1. The core boundary / constraint decision ->
The LLM receives only structured evidence generated by the detector, including account IDs, transaction IDs, counts, totals, thresholds, and time windows. The raw transaction dataset and individual transaction records are never sent to the LLM. Its role is limited to explaining precomputed evidence, not detecting patterns or making decisions. Multiple detected patterns can be grouped into a single API request to reduce call volume while keeping the input within the model's context window.
